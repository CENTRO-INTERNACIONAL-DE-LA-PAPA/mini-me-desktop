# Visualization Guidelines

The plots that are generated by the agents or sub-agents (with any plotting library like matplotlib, ggplot or D3.js) must follow the following visualization guidelines:

- **Clarity**: The plot should be clear and easy to understand.
- **Consistency**: The plot should follow a consistent style and layout.
- **Precision**: The plot should be precise and accurate according to the information.
- **Efficiency**: The plot should allow users understand the plot easily.
- **Esthetic**: The plot should be visually appealing and aesthetically pleasing.
- **Context**: The plot should provide context and background information.
- **Good ink-data ratio**
- **Accessibility**: The plot should be accessible to all users, including those with disabilities like color blindness.
