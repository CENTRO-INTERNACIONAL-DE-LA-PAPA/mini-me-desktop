# Report Structures

Choose the structure based on the audience and decision context.

## Scientific report

Use when:

- the audience expects methods and caveats
- the report may be reviewed by researchers or analysts
- multiple analysis stages need to be preserved clearly

Suggested structure:

1. Title
2. Objective
3. Data and Scope
4. Methods Overview
5. Key Findings
6. Limitations and Caveats
7. Recommendations and Next Steps
8. References
9. Appendix

## Executive summary

Use when:

- the audience is decision-focused
- time is limited
- technical detail should be minimized

Suggested structure:

1. Title
2. Decision context
3. Key findings
4. Main risks or caveats
5. Recommendations
6. Immediate next steps

Keep it short. Move technical detail to a brief appendix only if needed.

## Technical memo

Use when:

- the audience is technical
- concise but method-aware communication is needed
- the report is more operational than publication-style

Suggested structure:

1. Objective
2. Data and assumptions
3. Analytical approach
4. Key results
5. Caveats
6. Recommended follow-up

## Section ordering rule

Put the most decision-relevant content earlier.

For most reports:

- objective before methods
- findings before extended caveats
- recommendations after the evidence is established
