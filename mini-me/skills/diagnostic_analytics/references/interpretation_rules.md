# Interpretation Rules

- Prefer "associated with" by default.
- Use "consistent with an explanation" when the evidence is suggestive but not decisive.
- Use stronger causal language only when the design supports it.
- Report effect sizes and uncertainty, not just significance.
- If estimates are unstable because of collinearity, say so explicitly.
- If conclusions depend strongly on controls, note that the explanation is sensitive to model specification.
- If the data quality limits interpretation, say that the diagnostic result is provisional.
